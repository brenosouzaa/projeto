# NFC Point

Sistema de página digital para estabelecimentos acessada por NFC e QR Code.

## Funcionalidades

- Landing page do NFC Point
- Login e criação de acesso
- Painel administrativo
- Cadastro, edição, pausa e exclusão de estabelecimentos
- Página pública personalizada por estabelecimento
- Links para WhatsApp, Instagram, Google Maps, catálogo e site
- Geração de QR Code
- Métricas de visualizações e cliques
- Integração com Supabase
